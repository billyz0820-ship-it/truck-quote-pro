# 密码加密说明

## 概述
项目实现了基于XOR算法的对称加密功能，用于保护用户密码在传输过程中的安全性。

## 加密算法

### 1. XOR对称加密
- **算法**: XOR（异或）对称加密
- **密钥**: `0123456789abcdef`（16位十六进制字符）
- **输出**: 十六进制字符串

### 2. 加密流程
```
明文密码 → XOR加密 → 十六进制字符串 → 传输到服务器
```

### 3. 解密流程
```
十六进制字符串 → XOR解密 → 明文密码
```

## 使用方法

### 1. 基本加密
```typescript
import { encryptPassword, decryptPassword } from '@/utils/crypto';

// 加密密码
const password = 'mypassword123';
const encrypted = encryptPassword(password);
console.log(encrypted); // 例如: "4a5b6c7d..."

// 解密密码（仅用于测试）
const decrypted = decryptPassword(encrypted);
console.log(decrypted); // "mypassword123"
```

### 2. 加盐加密
```typescript
import { encryptPasswordWithSalt } from '@/utils/crypto';

// 加盐加密
const password = 'mypassword123';
const { encrypted, salt } = encryptPasswordWithSalt(password);
console.log('加密结果:', encrypted);
console.log('盐值:', salt);
```

## 安全特性

### 1. 对称加密
- 使用固定密钥 `0123456789abcdef`
- 加密和解密使用相同的密钥
- 算法简单高效，适合前端加密

### 2. 十六进制编码
- 加密结果转换为十六进制字符串
- 便于在HTTP请求中传输
- 避免特殊字符问题

### 3. 盐值支持
- 支持加盐加密增强安全性
- 每次加密可以生成不同的盐值
- 防止彩虹表攻击

## 技术细节

### 1. XOR加密实现
```typescript
const xorEncrypt = (text: string, key: string): string => {
  let result = '';
  for (let i = 0; i < text.length; i++) {
    const charCode = text.charCodeAt(i);
    const keyChar = key.charCodeAt(i % key.length);
    const encrypted = charCode ^ keyChar;
    result += encrypted.toString(16).padStart(2, '0');
  }
  return result;
};
```

### 2. 密钥循环使用
- 密钥长度为16个字符
- 密钥循环使用，覆盖整个明文
- 确保每个字符都被加密

### 3. 十六进制转换
- 每个加密后的字符转换为2位十六进制
- 使用 `padStart(2, '0')` 确保格式统一
- 便于传输和存储

## 注意事项

### 1. 前端加密限制
- 前端加密只能保护传输过程
- 密钥在前端代码中可见
- 不能替代HTTPS传输

### 2. 安全建议
- 必须使用HTTPS协议
- 服务器端应再次验证和加密
- 考虑使用更安全的加密算法（如AES）

### 3. 密钥管理
- 当前密钥硬编码在代码中
- 生产环境应考虑动态密钥管理
- 定期更换密钥增强安全性
